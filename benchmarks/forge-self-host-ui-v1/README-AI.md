# Forge Self-Host UI v1

This is a **design target authored as Forge XAML**, not a direct implementation of Forge's application shell.

It explores the requested development-tool layout:

- native-style menu bar
- CommandBar toolbar with icon + text commands
- slim activity rail
- full-height Projects panel
- Source editor beside the live Designer
- Inspector / Visual Tree / Toolbox panel
- contextual controls inside each panel
- global status bar

Use this screen inside Forge to review and iterate on Forge's own future UI before porting the accepted design into the application shell.

The current live application receives only the minimal structural fix needed to make Projects and Source usable separately. The menu/toolbar/shell redesign should be iterated here first.
