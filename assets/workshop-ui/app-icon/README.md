# Workshop app icon

Official primary Workshop app-icon direction: **Icon A** from the approved Workshop UI asset concepts.

The orange cube on a graphite rounded-square tile is the canonical Workshop product mark.

- `Workshop.ico` — multi-resolution Windows icon containing 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 px entries.
- Full raster production pack is distributed separately as `workshop-app-icon-pack.zip`.

The icon should be reused consistently for executable/window identity, shortcuts and Workshop product branding.
